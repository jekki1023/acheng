# ACheng AI

ACheng AI 商品采集与相关小项目集合。

## 仓库结构

每个插件都放在独立目录中，并单独发布 Release ZIP。下载某个插件时，请进入对应插件的 Release，不需要下载整个仓库。

## 插件列表

### AI Product Capture

目录：`ai-product-capture-extension/`

支持淘宝、1688、Coupang 的 AI 商品信息采集。

- 插件说明：[ai-product-capture-extension/README.md](ai-product-capture-extension/README.md)
- 独立下载：进入本仓库的 [Releases](https://github.com/jekki1023/acheng/releases) 页面，下载对应版本的 ZIP

## 下载规则

- 查看源码：进入对应插件目录
- 单独安装插件：下载对应 Release 的插件 ZIP
- 不建议直接使用仓库首页的 `Code → Download ZIP`，因为它会下载总仓库中的所有插件

## 维护方式

总仓库统一维护多个插件；每个插件独立版本化、独立打包、独立发布，互不影响下载和安装。
